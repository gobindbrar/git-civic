Build a polished full-stack web application called **GIT Civic — Get Involved Today**.

GIT Civic helps ordinary people discover official government and community meetings, understand what is happening in plain English, participate, and build an evidence-backed record of their civic involvement called a **Civic Passport**.

Tagline: **Find it. Show up. Prove it.**

IMPORTANT:
- This is a hackathon MVP, so prioritize a beautiful, convincing, working demo over unnecessary complexity.
- Use TypeScript throughout wherever practical.
- Make the application mobile-responsive but optimized for a desktop hackathon demonstration.
- Do not add political opinions, partisan recommendations, candidate endorsements, or tell users what position to take.
- The AI experience should explain government information neutrally using official-source information.
- Do not fabricate claims that attendance has been government-certified.
- Verification methods must be clearly labeled.
- Do not put API keys or secrets directly in source code.
- Keep secrets in environment variables.
- Preserve the existing Git repository.
